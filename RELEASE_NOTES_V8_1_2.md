# ITOS v8.1.2 — Injection-Pinbar Small-Tip Update

- Added the user-defined **Small-Tip Injection-Pinbar (Bottom)** structure.
- Candle colour is ignored.
- Requires a very large body (>=85%), almost no upper wick (<=3%), and a small visible lower tip (<=8%).
- Preserved the original classic lower-injection-wick structure.
- Added variant metadata and dashboard details.
- Both variants require recent-bottom or short-downmove context and remain subject to all existing safety gates.
