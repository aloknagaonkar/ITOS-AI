# ITOS v8.4.0 Release Notes

## Purpose

Organize the existing ITOS v8.3 information into two tabs while preserving the established user interface, theme, cards, charts, sidebar, and trading logic.

## Navigation

### Live Market Intelligence
Contains live decision-making information, including data health, market levels, institutional confirmation, decision intelligence, institutional flow, trigger checklist, market cycle, recommendations, active trade lifecycle, price confirmation, and current OI activity.

### Intelligence Explorer
Contains historical pattern intelligence, historical similarity and replay, decision audit, historical trade tracking, institutional flow memory and charts, detailed option chain, Greeks, OI walls, and methodology information.

## Preserved

- Existing v8.3 UI styling and layout components
- Upstox authentication and data retrieval
- Recommendation and confidence engines
- Trigger checklist
- Institutional and historical engines
- Snapshot storage and trade tracking
- Existing charts, tables, expanders, and sidebar controls

## Additional change

A compact sidebar version banner identifies the running build as ITOS v8.4.0.
