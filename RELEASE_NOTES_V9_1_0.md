# ITOS v9.1.0

## Added
- Question heading: **What changed in the last 5 minutes?**
- Live comparison of market, directional, trigger, and calibrated confidence.
- Side-rotation detection when the preferred CE/PE direction changes.
- Plain-language strengthening, weakening, or stable momentum summary.
- Question heading: **What should I watch next?**
- Dynamic next-confirmation watchlist based on current missing trigger conditions.

The change panel begins populating after multiple refreshes span roughly five minutes.
