# Architecture Notes
The repository-free engine accepts `DecisionContext`, reads upstream results without mutation, and emits one frozen result. `DecisionPipeline` creates the instance after flow and regime exist, stores it in `engine_results` and the typed context, then exposes the identical object in `PipelineResults` and the dashboard compatibility mapping. `app.py` only renders supplied fields. No persistence, Streamlit, repository, recommendation, safety or AI-trade dependency exists in the engine.
