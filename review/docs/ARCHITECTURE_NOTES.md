# Architecture Notes

The repository-free `DecisionConfidenceEngine` consumes only completed typed results in `DecisionContext`; it neither queries storage nor imports Streamlit. The pipeline creates the result once after data health is available, installs the identical object into `DecisionContext`, returns it in `PipelineResults`, and exposes it through the existing dashboard mapping. `app.py` renders fields only and performs no confidence calculation. Existing engine execution is retained; Decision Confidence is appended after required inputs and has no path into recommendation or safety enforcement.
